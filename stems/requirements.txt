# Sonoscope stem separation. Tested with Python 3.12 on macOS (Apple M3 Pro).
# System dependency: ffmpeg + ffprobe on PATH (not pip-installable).
#
# Key pins and why:
#   demucs==4.0.1      last release on PyPI; the project is no longer maintained.
#   torch==2.5.1 / torchaudio==2.5.1
#                      Demucs writes wavs with torchaudio.save. torchaudio 2.9
#                      moved save/load onto torchcodec, which demucs 4.0.1 doesn't
#                      know about, so stay on the 2.5 line (verified working here).
#                      The two versions must match each other.
#   soundfile          gives torchaudio 2.5 a reliable wav backend on macOS/Linux.
#   certifi            python.org builds on macOS ship without CA certs, so the
#                      first-run model download fails with CERTIFICATE_VERIFY_FAILED;
#                      separate.py points SSL_CERT_FILE at certifi's bundle.
#   numpy 2.x          works with torch 2.5.1 (verified).
#
# For a CUDA machine, install the matching CUDA build of torch 2.5.1 first, e.g.
#   pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
# then `pip install -r requirements.txt`.
